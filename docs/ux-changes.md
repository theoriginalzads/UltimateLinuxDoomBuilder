# What's different from Ultimate Doom Builder

A user-facing list of every intentional UI or behaviour difference between ULDB and upstream UDB, with the reason for each. If something moved, it's listed here.

| Area | Change | Reason |
|---|---|---|
| Resource list (Open Map, Map Options) | Icons are simple vector glyphs instead of upstream's bitmaps; missing resources show red text instead of a pink row | Upstream's ImageList can't be loaded on Linux; red reads better in dark mode |
| Resource list | Reorder by dragging an item onto another (no insertion marker yet) | Avalonia's ListBox has no built-in reorder; a marker is to come |
| Open Map, Add Resource | Native look (Avalonia Fluent theme, follows the desktop's light/dark setting); same controls, labels and order | New toolkit |
| Errors and Warnings | A list of icon + text rows instead of a grid; says "No errors or warnings." when empty; text is selectable; window slightly wider so the bottom row fits | Clearer, less dense (plan section 4) |
| Info panel (bottom of the main window) | Groups are rounded cards instead of captioned grey boxes; field names dimmed, values in normal text; textures/flats/sprites as 64 px tiles with a size badge and the name below; flags as a check-marked list; expand/collapse is a chevron. Same fields, order and grouping. Panel is 126 px tall (UDB: 106) | Main-window modernisation (plan section 4); approved by the user with screenshots, 20 Oct 2026 |
| Info panel, nothing highlighted | Shows the mode name and map statistics also in Debug builds (upstream Debug builds show a debug console there) | ULDB doesn't show the debug console |
| Dockers (side panel) | Same place, tabs and behaviour (auto-hide, pin, resize); tabs are flat buttons with an accent highlight, the selected docker's name is shown as a heading, and the pin button shows a pushpin (upright = stays open, tilted = auto-hide) instead of arrows | Modernisation; pin icon chosen by the user, 20 Oct 2026 |
| Open Map dialog | Larger minimum size (500×700) so the maps list and resources never overlap | Fix after user testing |
| Edit dialogs (Edit Vertex first) | Same tabs, groups, fields and order; groups are rounded outlines with a bold title; number boxes have slim up/down buttons; the custom fields grid has flat headers with a sort arrow and inline editors | Modernisation (plan section 4); approved by the user, 20 Oct 2026 |
| Thing type tree | Thing icons are coloured dots (things) and folders (categories) in the editor's thing colours, instead of UDB's bitmaps; rows are compact | ImageList data in .resx can't be loaded on Linux; user liked the tighter list |
| Edit dialogs: action help button | Removed (the book icon beside the action) | ULDB isn't reworking the help file; user decision, 20 Oct 2026 |
| Edit dialogs: density and alignment | Compact controls app-wide (13 px text, 26 px fields, 22 px flag rows); one shared label column per tab; texture previews fill the Front/Back tabs' right column; Linedef Properties fits without scrolling | User review with UDB screenshots, 20 Oct 2026 |
| Toolbar, menu and button icons | Toolbars, mode buttons, menus, the status bar and dialogs' small image buttons (reset, browse, clear, link…) use ULDB's vector icons in KDE Breeze style (16 px grid, 1 px strokes, theme text colour, Breeze accent colours). Each one is matched to the UDB picture it replaces (by action, item name or the UDB image itself), so state icons (lights, models, info panel, warnings) still change as in UDB. Picture boxes in dialogs (warnings, hints) use the same icons. Kept as UDB's pictures: the splash and About artwork, large error/warning pictures, test-engine icons, thing sprites and textures | User request, 20 Oct 2026: modernise the main window; Breeze look |
| First start | If ULDB has no settings yet and finds UDB settings (Mono build, Flatpak, Wine), it asks whether to import them, then shows a summary. `--import-udb-settings[=PATH]` imports on request. See [settings-import.md](settings-import.md) | New in ULDB (plan Phase 7, settings import); upstream has no import |
| Edit-modes toolbar (left) | Scrolls when it's taller than the window (likely on small screens, now that every plugin adds its modes) instead of running under the info panel | All nine plugins add their modes there |
| Number boxes in plugin dialogs | Same slim box with stacked arrows as the core dialogs (Avalonia's stock NumericUpDown has wide side-by-side buttons) | Consistency |
| Plugin dialogs (slope data sector, Stair Sector Builder, BuilderEffects' forms) | Same controls, labels and order as UDB, in the card style of the approved edit dialogs; the slope data sector help text is native text instead of an embedded web page | Modernisation; not yet reviewed by the user |
| Plugin dockers (Tag Explorer, Comments, Sound Environments, 3D floors, Undo/Redo) | Same contents and behaviour; list and tree icons are Breeze-style element icons (UDB's are in .resx image lists that can't be read on Linux); Comments' grid is a plain list with the type icon; 3D floors are cards with the highlighted floor outlined in the accent colour | New toolkit; not yet reviewed by the user |
| Help menu | "Reference Manual" (UDB's help file) and "Check for updates" are hidden; "GitHub issues tracker" is now "ULDB on GitHub" and opens ULDB's repository; About is "About Ultimate Linux Doom Builder..." | User request, 20 Oct 2026: ULDB isn't reworking the help file yet; UDB's updater isn't part of ULDB |
| About window | ULDB's own: Cacky, name, version (early preview), the unofficial-fork and AI-disclosure notice, links to ULDB, its issues and upstream UDB, credits | User request; the plan's About requirements (section 6) |
| Main window title | No "(64-bit)" after the program name | User request |
| Toolbars (main, mode controls, edit modes) | When the buttons don't fit, the rest go into a » drop-down instead of scrolling or clipping, as UDB's ToolStrip does | Issue fixes, 20 Oct 2026 |
| Tree views (thing types, etc.) | Rename in place (label editing); expanding no longer scrolls back to the selection | Issue fixes |
| Comments panel / link buttons | Comment type icons (regular, info, question, problem, smile) and link/unlink icons in Breeze style; placeholder text is dimmed | Issue fixes |
| Undo/Redo panel | Compact rows, highlight for the current step; clicking a level undoes/redoes to it | Issue fixes |
| Opening a map | A dimmed "Opening map..." cover appears while the map loads, since the window can't repaint during the load | Issue #13 |
| Unexpected error window | ULDB's own port of UDB's (system info for Linux, Continue/Quit, link to ULDB's issue tracker) | Issue #7 |
| Texture and flat browser | Same sets tree, filter, size, "used first", classic view and size filters; the tile grid is drawn natively (size badges, accent-colour selection, the group title across the top); the tree's icons are vector icons. Opens larger (1000x640) the first time | Phase 3 port; not yet reviewed by the user |
| Preferences, Game Configurations, Map Options, Grid Setup, Go To Coordinates, Change Map, Things Filters, Tag/Thing statistics, Paste Special, Texture Set, thing/effect browsers, Doom/Hexen-format edit forms | Same fields and order as UDB in the card style of the other dialogs. The script editor preview is live | Phase 3 ports; not yet reviewed by the user |
| Script editor | A new editor engine instead of upstream's Linux one (a plain text box with stubbed Scintilla calls): syntax highlighting with the colours from Preferences, JetBrains Mono (bundled, OFL), line numbers, current-line highlight, matching braces, same-word highlights, error markers and red error lines, folding, autocompletion and call tips from the script type's keyword lists, auto indent and auto-close brackets. Tabs show a dot while a document has unsaved changes and a close button; errors list under the editor, double-click goes to the line. Search can't crash it any more | User request, 20 Oct 2026: upstream's Linux editor draws lines through the text and crashes on search |
| Dialog fixes from issues #17, #19, #20 | Dialogs have no minimise button (a minimised dialog left the main window blocked). Game Configurations: clicking a row's text selects it, the box ticks it, tighter rows, the Windows-only "short paths"/"Linux paths" options are hidden. Preferences: colour names aren't cut off, the script editor preview works, eight extra colour presets (Monokai, Dracula, One Dark, Nord, Gruvbox Dark, Solarized Dark/Light, GitHub Light), Builder Modes' "Editing" and 3D Floor Mode's tabs are shown | Issues #17, #19, #20 |
| Icons for the menu items that had none (issue #18) | New Breeze-style icons for File (open in current WAD, close, save as/into, import, export and its three items, exit), Edit (grid items), View (always show vertices, go to coordinates, fit to screen, expanded info panel), Prefabs (create), Linedefs (select single/double-sided, split, change index, update lightfog, align textures and its four items) and the Change Index items. Left without icons on purpose: recent files, zoom percentages, thing filter and skill lists | Issue #18; not yet reviewed by the user |
| Dialogs open centred on the main window; main window remembers size and place | A dialog with no saved position opens in the middle of the main window (the About window included); the main window restores its last size, place and maximised state (a first start keeps ULDB's default size). On Wayland the compositor may ignore the saved place | User request, 21 Oct 2026 |
| Command palette | An overlay with a search box and the action list (recent first, then commands, then ones not available in the current mode, dimmed), same search rules as UDB | Leftover placeholder |
| *(More entries are added as UI work continues in Phase 3.)* | | |
